# Worklane Tools 2026-10-24 delivery

This is a **local, preview-only, noindex** build of 35 tools. The 5 newly implemented tools are:

- `apps/fencebid/index.html` — fence run/gate material and labor estimate
- `apps/mulchcompare/index.html` — bagged vs bulk mulch costs
- `apps/weddingflow/index.html` — wedding photographer timeline with coverage conflict and ICS export
- `apps/turnoverbudget/index.html` — landlord turnover and vacancy expense budget
- `apps/feenet/index.html` — payment processing fees and net receipts comparison

The previous 30 tools, `content/catalog.json`, `content/history.json`, `scripts/build.py` and `scripts/qa.py` remain part of the same repo. This batch appends five new entries without modifying earlier app sources.

## Build locally

```bash
python scripts/build.py
python scripts/qa.py
python scripts/test_2026_10_24.py   # needs Playwright Python and a system Chromium binary
```

Open `dist/index.html` or serve the `dist/` directory locally (`python -m http.server 8000 --directory dist`). Preview build intentionally disallows indexing and never loads AdSense. Do not change `noindex` to `index` until page quality, domain ownership, site legal pages, source review and functional HTTPS checks have passed.

## Deploy only after authorization

1. Create a **writable** GitHub repository and push this project. Connect it to Cloudflare Pages or Vercel.
2. In Cloudflare Pages, use build command `python3 scripts/build.py` and output folder `dist` for a public preview that defaults to `noindex`. Set `SITE_URL` to the project's actual `https://*.pages.dev` origin to emit canonical URLs while keeping every page `noindex` and the sitemap empty. Do not set a placeholder URL.
3. Verify real owned domain, HTTPS, working `/tools/<slug>/` routes, privacy and contact pages.
4. For approved production pages only, set `approved_for_index`, `evidence_reviewed`, `qa_verified` after independent QA, then run `python scripts/build.py --production --site-url https://YOUR_ACTUAL_OWNED_DOMAIN`. **Do not use placeholder domains**. Verify `sitemap.xml`, `robots.txt`, `canonical` and Search Console.
5. Do not configure `ADSENSE_PUBLISHER` unless site review is approved, privacy/cookie obligations are met and publisher ID is real. Build gates require `--ads-approved --privacy-ready`. There is no checkout, payment processing or subscription entitlement logic in this deliverable.

**Important:** Local build, GitHub commit, sitemap creation, Search Console discovery, Google indexing and AdSense approval are separate stages. None of the latter four occurred during this run.
