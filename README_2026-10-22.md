# Worklane Tools · 2026-10-22 handoff

This project contains 25 independently functioning HTML/CSS/JS tools under `apps/<slug>/index.html`. The 5 newest are `concreteyield`, `photovaultplan`, `reserveready`, `marginwatch`, and `travelbuffer`. The previous 20 app source files remain byte-for-byte unchanged.

## Local run

```bash
python scripts/build.py
python scripts/qa.py
python scripts/test_2026_10_22.py
python -m http.server 8000 --directory dist
```

Then open `http://localhost:8000` in your browser. Browser smoke tests use Playwright with `/usr/bin/chromium` and `page.set_content()` because this automation environment blocks Chromium navigation even to local URLs. On your own machine, real-origin browser tests are still required.

## Publishing

Do not deploy the preview `dist/` expecting SEO: it intentionally contains `noindex` and a disallow-all `robots.txt`. For a **real, owned HTTPS domain** and reviewed, approved tool pages:

1. Connect your authorized GitHub repository to Cloudflare Pages or Vercel. Build command: `python scripts/build.py --production --site-url https://YOUR_OWNED_DOMAIN` and output folder: `dist`.
2. Review and update the `about`, `privacy`, and `terms` templates with true operator details and actual data processing. They are placeholders, not a substitute for legal review.
3. Mark *only human-approved* catalog items `approved_for_index=true`, `evidence_reviewed=true`, and `qa_verified=true`. These flags are manual attestations, not automated evidence of real-world quality.
4. Build, run QA, check HTTPS and canonical tags, then submit the actual `/sitemap.xml` in Google Search Console. A submitted sitemap does not guarantee indexing.
5. Add AdSense only after account and site approval, a real `ca-pub-...` ID, accurate privacy notices and required consent controls. `build.py` gates injection behind explicit flags but cannot verify AdSense approval itself.

**No public deploy, Search Console data or ad revenue is claimed in this handoff.**
