# Worklane Tools — 2026-10-23 deployable snapshot

This package includes **30 standalone English H5 tools**, the historical idea registry, source scripts, and a prebuilt static `dist/` preview. Five tools were added on 2026-10-23: `metersplit`, `clientrename`, `visitfloor`, `rushquote`, `warrantynest`.

## Run locally

From the project root:

```bash
python scripts/build.py
python scripts/qa.py
python -m http.server 8080 --directory dist
```

Open `http://localhost:8080/`. No npm dependencies, backend, API keys or payment configuration are required for the free tools. `clientrename` ZIP is assembled locally and does not upload photos.

## Safe release process

1. Create an authorized GitHub repository and connect a static host (Cloudflare Pages or Vercel). Use the `dist` output directory. Commit `apps`, `content`, `intake`, `scripts`, and site config. Do **not** commit private payment credentials.
2. Register and verify a real `.com` domain, then replace the example URL by invoking `python scripts/build.py --production --site-url https://YOUR-OWNED-DOMAIN` only after you actually own it.
3. Each tool needs **all three** catalog gates `approved_for_index`, `evidence_reviewed`, `qa_verified` to be true before it enters the production sitemap. Do not change these flags merely to inflate page counts.
4. Validate every public HTTPS tool, `robots.txt`, `sitemap.xml`, canonical URL, real business contact and accurate privacy pages. Confirm Google Search Console ownership, then submit the real sitemap and monitor index coverage.
5. AdSense is **off by default**. To activate, obtain site approval and a real `ca-pub-...` ID, implement applicable consent/privacy obligations and build with `--adsense-publisher ... --ads-approved --privacy-ready`. Verify actual `ads.txt` and ad placement. Do not simulate revenue or ad clicks.
6. For subscription billing, use an approved payment provider and server-side webhooks/entitlement verification. There is no payment processing or live subscription in this package.

## Testing limitation

Node syntax and static QA pass; five new tools passed Chromium mobile interactions via `set_content`. The sandbox browser blocked localhost HTTP navigation, so real-domain routes, iOS Safari, persistence and full accessibility still require deployment testing.

## Data integrity

`content/history.json` is the de-duplication source of truth and must persist in the remote Git repository. Each daily build must first compare its five new user tasks against this history. All new pages remain `noindex` until approved.
