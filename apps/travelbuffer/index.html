This does not estimate driving time, access traffic, sync with a live calendar, prevent external bookings or send invitations. You enter buffer durations. Calendar export uses the time zone of this device at creation; verify imported times, especially when traveling.

Block travel time around appointments, not just the appointment itself

On-site consultants, tutors, inspectors and other mobile service providers may need a 60-minute client appointment but 45 minutes to drive there and 30 minutes afterward. Standard calendar events that reserve only the client-facing time can create double bookings.

How the conflict check works

Each appointment has a blocked start (scheduled start minus pre-visit buffer) and blocked end (scheduled end plus post-visit buffer). Overlapping blocked intervals count as conflicts. Export an iCalendar file that reserves the entire block as busy, then import it into your calendar and verify its time zone.

This MVP does not calculate route times or expose a booking page to clients. It solves the planning and calendar-export task only; real-time booking integration is a future hypothesis.
