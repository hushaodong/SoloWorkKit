Make client filenames readable without uploading originals

Camera files often arrive with technical names such as DSC_1234.jpg. A consistent delivery name can include the client or project and a padded sequence number. ClientRename previews the new names before creating a ZIP containing renamed copies. The original files on your computer or phone are never renamed.

This lightweight tool deliberately avoids image editing, watermarking and metadata changes. It is not a replacement for a full photo catalog. Select no more than 100 JPEG, PNG or WebP files, confirm the sequence and download one ZIP. Files stay inside the browser tab; export promptly because the tool does not store a gallery or keep backups. For very large RAW batches, use desktop photo-management software instead.
