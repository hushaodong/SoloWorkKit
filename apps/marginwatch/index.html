Catch a fixed-price project margin problem before delivery

Tracking time is not the same as knowing whether a project remains profitable. MarginWatch compares a fixed client quote with internal labor cost, outside expenses, actual logged hours and an explicit remaining-hours estimate. The completion forecast updates every time you log work.

What “margin” means here

Forecast profit = quote − (completed hours + estimated remaining hours) × internal labor cost − fixed outside costs. Forecast margin = forecast profit ÷ quote, when quote is greater than zero. This is a contribution estimate, not a tax return or full financial statement.

Use the gap between planned and forecast profit as a prompt to renegotiate scope or improve estimation—not as proof a client owes more money. Entries stay in local storage and can be exported to CSV.
